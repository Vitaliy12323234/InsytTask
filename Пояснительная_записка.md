## 1. Использованный подход

Классификация выполнена **локальной LLM** `qwen3.5:9b` через Ollama. Скрипт `classifierLLM.py` выполняет только транспортную функцию: читает `tikets.csv`, отправляет запрос к модели, парсит JSON-ответ, пишет `result.csv`. **Вся бизнес-логика** — правила категоризации, правила ручной обработки, приоритеты — описана в системном промпте (приложение A) и выполняется моделью.

**Автоматизация:** факт использования LLM и скриптов не скрывается. Исходный код и полный текст промпта приложены в архиве.

---

## 2. Применение правил категоризации и ручной обработки

Правила из ТЗ реализованы **в системном промпте**. Python не содержит `if`, `re.search` или словарей для проверки текста.

### 2.1. Обязательная ручная обработка
Модель присваивает `category="Не определено"`, `tag="Требует ручной обработки"`, `requires_manual_review=true`, если выполнено хотя бы одно условие:
1. Строка пустая или только пробелы.
2. Длина текста (без крайних пробелов) < 5 символов.
3. Нет ни одной буквы русского алфавита (А–Я, а–я, Ё, ё).
4. Только эмоция без описания проблемы.

### 2.2. Категоризация
Если правила ручной обработки не сработали — модель выбирает одну из 5 категорий ТЗ согласно описаниям в промпте.

### 2.3. Теги
«Авторизация» и «Ошибка загрузки» → «Технический»; «Организационные вопросы по обучению», «Ошибки в контенте/методологии», «Не завершается обучение» → «Организационный».

### 2.4. Приоритеты на смешанных обращениях
- вход/пароль → «Авторизация»;
- видео/файл/404/500 → «Ошибка загрузки»;
- назначить/отменить/продлить/открыть доступ → «Организационные вопросы»;
- сертификат/прогресс/статус → «Не завершается обучение»;
- неверный ответ/опечатка → «Ошибки в контенте/методологии».

## 3. Спорные (пограничные) случаи

| Обращение (сокр.) | Решение | Обоснование |
|---|---|---|
| «Не грузит видео, не могу пройти курс» | Ошибка загрузки | Корень — воспроизведение (приоритет «видео → Ошибка загрузки») |
| «Курс пройден, прогресс не засчитан» | Не завершается обучение | Маркер «прогресс/сертификат» |
| «Прошу предоставить доступ к курсу» | Организационные вопросы | Запрос действия с курсом, не сбой входа |
| «Забыл пароль, письмо не приходит» | Авторизация | Приоритет «пароль → Авторизация» |
| «Кошмар!!!», «Очень плохо!!!», «Безобразие!!!» | Ручная обработка | Только эмоция |
| «Ок», «Аа», «Жду», «Нет» | Ручная обработка | Длина < 5 символов |
| «Help», «404», «Error 500», «login failed» | Ручная обработка | Нет кириллицы |
| Пустые строки / строки из пробелов | Ручная обработка | Правило пустой строки |

Если по итогам прогона модель ошиблась на каком-то из этих случаев — `result.csv` скорректирован вручную с сохранением исходных `id`, `text` и порядка записей.

## Приложение A. Полный текст системного промпта

Ты — эксперт техподдержки корпоративной образовательной платформы (LMS).
Классифицируй обращение пользователя.

### ШАГ 1. Ручная обработка.
Если выполнено ХОТЯ БЫ ОДНО условие — верни category="Не определено", tag="Требует ручной обработки", requires_manual_review=true:
  1) строка пустая или только пробелы;
  2) длина текста (без крайних пробелов) меньше 5 символов;
  3) нет ни одной буквы русского алфавита (А-Я, а-я, Ё, ё);
  4) только эмоция без описания проблемы (например: «Кошмар!!!», «Спасибо!», «Ура!»).

### ШАГ 2. Иначе выбери ОДНУ из 5 категорий:
  1. "Авторизация" — вход, пароль, восстановление доступа, активация учётной записи.
  2. "Ошибка загрузки" — сбои открытия, передачи и воспроизведения страниц, файлов, видео.
  3. "Организационные вопросы по обучению" — назначение/отмена курсов, зачисление в потоки, расписание, сроки, запрос доступа к курсу.
  4. "Ошибки в контенте/методологии" — опечатки, неверные формулы, противоречия материалов, ошибки в условиях заданий.
  5. "Не завершается обучение" — не сохраняется прогресс, не засчитываются результаты, не выдаётся документ при выполненных условиях.

### ПРИОРИТЕТ:
  - вход/пароль → "Авторизация"
  - видео/файл/страница/404/500 → "Ошибка загрузки"
  - назначить/отменить/продлить/удалить/открыть доступ → "Организационные вопросы по обучению"
  - сертификат/прогресс/статус → "Не завершается обучение"
  - неверный ответ/опечатка → "Ошибки в контенте/методологии"

### ТЕГИ:
  "Авторизация", "Ошибка загрузки" → "Технический"
  "Организационные вопросы по обучению", "Ошибки в контенте/методологии", "Не завершается обучение" → "Организационный"
